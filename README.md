# המרכז לתולדות הטבע במורשת ישראל: תצוגת העיצוב החדש

**[לפתיחת התצוגה](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/AmarShaked/center-site-demo/main/blueprint.json)**

התצוגה רצה בתוך הדפדפן (WordPress Playground): וורדפרס שלם עם ערכת העיצוב החדשה ותוכן לדוגמה, בעברית ובאנגלית.

- הטעינה הראשונה לוקחת כחצי דקה.
- שינויים לא נשמרים: האתר נבנה מחדש בכל פתיחה.
- התוכן הוא דוגמה. חלקו לקוח מהאתר הציבורי הקיים, וחלקו (חוקרים, פעילויות ואירועים) הוא דוגמה בלבד.
- התצוגה נפתחת כמנהל, כך שאפשר להיכנס גם לממשק הניהול (`/wp-admin`).

הקבצים במאגר: `center-theme.zip` (ערכת העיצוב), `center-core.zip` (התוסף של המרכז), `center-demo.zip` (תוכן לדוגמה, רק לתצוגה, לא להתקנה באתר האמיתי).
